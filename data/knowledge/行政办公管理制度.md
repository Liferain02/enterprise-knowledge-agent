# 行政办公管理制度

## 第一章 总则

### 第一条 目的

规范公司行政办公管理，提升工作效率，树立良好企业形象。

### 第二条 适用范围

公司全体员工和各部门。

## 第二章 办公区域管理

### 第三条 办公时间

- 工作日：周一至周五
- 上班时间：09:00
- 下班时间：18:00
- 午休时间：12:00-13:00

### 第四条 门禁管理

1. 员工入职后办理门禁卡
2. 门禁卡限本人使用，不得转借
3. 离职时归还门禁卡
4. 门禁卡丢失需立即报告

### 第五条 访客管理

1. 访客需在前台登记
2. 领取临时访客证
3. 由被访部门人员接待
4. 访客离场时归还访客证

### 第六条 办公环境

1. 保持办公区域整洁
2. 个人物品摆放有序
3. 不得在办公区域用餐
4. 爱护公共设施

## 第三章 办公设备管理

### 第七条 计算机管理

1. 个人计算机专人专用
2. 不得私自安装软件
3. 定期更新系统补丁
4. 离开座位需锁定屏幕

### 第八条 打印管理

1. 节约用纸，双面打印
2. 敏感文件需粉碎处理
3. 每月统计打印用量
4. 超出配额需说明原因

### 第九章 会议管理

**会议室预约**：
- 提前通过系统预约
- 预约需说明会议主题
- 提前5分钟入场
- 会议结束后清理现场

**视频会议**：
- 提前测试设备
- 发言需开启麦克风
- 保持网络畅通
- 重要会议需录屏

## 第四章 物资管理

### 第十条 办公用品

1. 每月定额发放
2. 需提前申请特殊用品
3. 领用需登记签名
4. 不得私自拿取

### 第十一条 固定资产

1. 编号登记入账
2. 定期盘点清查
3. 损坏需及时报告
4. 离职时办理移交

## 第五章 安全管理

### 第十二条 消防安全

1. 熟悉消防通道位置
2. 掌握灭火器使用方法
3. 不得占用消防通道
4. 发现隐患及时报告

### 第十三条 信息安全

1. 密码定期更换
2. 重要文件加密存储
3. 离开时锁定电脑
4. 警惕网络钓鱼

## 第六章 附则

### 第十四条

本制度由行政部负责解释，自2024年1月1日起施行。
