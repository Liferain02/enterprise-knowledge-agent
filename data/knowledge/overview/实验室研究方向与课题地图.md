# 实验室研究方向与课题地图

## 实验室定位

本实验室聚焦数据中心与云基础设施中的高性能系统软件，重点围绕以下方向开展研究：

1. 高性能计算系统（HPC）
2. 分布式系统与云计算
3. 高性能网络与 RDMA
4. 面向大规模节点的资源管理与调度
5. 分布式 NUMA / 远程内存 / 资源池化

实验室强调“系统设计 + 原型实现 + 定量评测”三位一体的研究路径，要求所有课题最终都能够落到可运行系统与可复现实验上。

## 方向一：高性能计算系统

### 关注问题

- 多核、多路 CPU 下的并行扩展性
- 内存层次与缓存一致性开销
- NUMA 架构下的线程放置、数据放置与负载均衡
- HPC 作业在通用云平台中的性能退化问题

### 典型关键词

- NUMA-aware scheduling
- memory locality
- CPU affinity
- cache coherence
- latency-sensitive workload

## 方向二：分布式系统与云计算

### 关注问题

- 多租户环境下的隔离与性能干扰
- 数据中心资源碎片化与弹性伸缩
- 微服务与 RPC 框架的系统开销
- 云原生基础设施与高性能网络协同

### 典型关键词

- datacenter operating system
- resource disaggregation
- cluster scheduling
- microservice performance
- tail latency

## 方向三：高性能网络与 RDMA

### 关注问题

- RDMA 在低延迟 RPC、远程内存访问中的使用模式
- 无内核绕过路径下的网络栈优化
- RDMA 与共享内存抽象结合时的一致性与编程模型
- 高带宽、低时延网络上的系统设计空间

### 典型关键词

- one-sided verbs
- two-sided verbs
- zero-copy
- RNIC queue pair
- congestion control

## 方向四：分布式 NUMA 与资源池化

### 核心研究动机

传统 NUMA 只局限于单机多路系统，但在现代数据中心中，CPU、内存、网络资源实际已经具备被跨节点统一编排的条件。分布式 NUMA 的目标，是在跨机器环境中尽量保留本地 NUMA 的低延迟语义，同时利用 RDMA 或其他低时延互联，将远端资源以可管理、可调度、可预测的方式暴露给应用。

### 当前重点问题

- 如何定义“远端 NUMA 节点”的统一抽象
- 如何让应用感知远端访问代价并主动优化数据布局
- 如何在系统层实现远程页迁移、远程缓存或远程内存映射
- 如何在多租户和资源动态变化条件下维持性能稳定性

### 近期重点子题

1. 基于 RDMA 的分布式共享内存原型
2. 分布式 NUMA 下的数据放置与线程调度
3. 面向微秒级服务的远程内存访问路径优化
4. 逻辑进程 / 资源池化抽象对分布式 NUMA 的支持

## 课题阅读建议

### 入门阶段

- 先理解单机 NUMA 的基本概念、页表、缓存一致性和线程绑定
- 再理解 RDMA 编程模型和数据中心低时延网络
- 然后阅读远程内存、资源池化、数据中心 OS 相关论文

### 进阶阶段

- 对比不同系统在接口抽象、资源管理、性能隔离上的取舍
- 把论文中的设计映射到我们自己的实验平台
- 针对“本地访问 vs 远端访问”的代价差异设计实验

## 组内建议

- 新成员优先熟悉实验室的环境配置、集群使用规范和实验记录模板
- 做系统论文阅读时，必须同时记录设计目标、核心机制、评测方法和局限性
- 做实验时，必须保留完整的配置、版本、数据路径和结果归档信息
