## 第二章 常见问题处理

### 2.1 计算机故障

**无法开机**
1. 检查电源连接
2. 尝试长按电源键10秒
3. 如仍无法开机，联系IT支持

**系统卡顿**
1. 重启计算机
2. 清理磁盘空间
3. 关闭不必要的后台程序
4. 如持续卡顿，提交工单

### 2.2 网络问题

**无法连接网络**
1. 检查网线/WiFi是否正常
2. 尝试重新连接WiFi
3. 重启计算机
4. 联系IT支持

**网速慢**
1. 关闭占用带宽的应用
2. 切换到5G WiFi
3. 检查是否有下载任务
4. 提交网速问题工单

### 2.3 软件问题

**软件无法打开**
1. 尝试重新启动软件
2. 检查软件是否更新
3. 重新安装软件
4. 联系IT支持

**邮件收发问题**
1. 检查网络连接
2. 确认邮件服务器设置
3. 检查邮箱容量
4. 联系IT支持

## 第三章 软件安装申请

### 3.1 常规软件

1. 提交软件安装申请单
2. 部门负责人审批
3. IT部门评估安全性
4. 统一安装部署

### 3.2 特殊软件

1. 说明软件用途
2. 提供软件授权
3. IT部门评估兼容性
4. 单独部署安装

## 第四章 账号权限管理

### 4.1 账号申请

1. 新员工入职：系统自动开通
2. 临时账号：需部门负责人审批
3. 外部人员：需VPN申请流程

### 4.2 权限申请

1. 提交权限申请单
2. 部门负责人审批
3. 业务负责人审批
4. IT部门开通

### 4.3 账号注销

1. 员工离职：系统自动处理
2. 项目结束：回收临时账号
3. 权限过期：自动回收

## 第五章 数据安全

### 5.1 数据备份

1. 服务器数据：每日备份
2. 个人文件：建议使用云盘
3. 重要数据：多重备份
4. 备份保留：30天滚动

### 5.2 数据恢复

1. 提交数据恢复申请
2. 说明恢复原因
3. IT部门评估
4. 恢复后确认

### 5.3 泄密处理

1. 立即报告IT部门
2. 切断泄漏途径
3. 评估影响范围
4. 采取补救措施
