# 高性能计算集群使用说明

## 一、文档目的

本说明用于规范实验室成员对计算集群、共享服务器和高性能网络设备的日常使用，重点服务于系统研究、分布式实验和性能评测任务。

## 二、基本原则

1. 所有作业必须可追踪
2. 所有长时间运行任务必须提前登记
3. 不允许在共享环境中随意修改系统级配置
4. 不允许未经说明长期占用 GPU、RDMA 网卡或大内存节点

## 三、账号与目录规范

### 账号

- 每位成员使用独立账号
- 不允许共享 root 密码或公用科研账号
- 需要 sudo 权限时，必须说明用途并登记

### 目录

推荐结构如下：

```text
/data/<username>/
  code/
  datasets/
  checkpoints/
  experiments/
  logs/
```

## 四、作业执行要求

### 短任务

- 调试类任务建议控制在 30 分钟内
- 调试任务优先在指定开发节点运行

### 长任务

- 训练、批量实验、长时压测必须提前说明
- 提交前确认输出目录和日志目录
- 需要占用特殊资源时，在组内同步

## 五、性能实验特别要求

对于高性能计算、RDMA、分布式 NUMA 等方向的实验，必须额外记录：

- CPU 绑定
- NUMA 绑定
- 网卡绑定
- hugepage 配置
- 内核参数
- 交换机与链路配置

## 六、资源清理要求

实验完成后必须清理：

- 僵尸进程
- 无用 checkpoint
- 临时缓存文件
- 长时间无人查看的日志目录

## 七、禁止行为

- 在共享节点直接跑不受控压力测试
- 未通知情况下重启服务
- 修改公共环境变量导致其他成员任务失败
- 占满存储而不清理历史输出

## 八、推荐实践

- 用脚本记录实验参数
- 每次实验生成单独目录
- 用 markdown 写实验摘要
- 重要实验结果同步到组会材料
