# 实验室常见问题 FAQ

## 一、账号与环境

### Q1：服务器账号怎么开通？

先联系实验室管理员登记姓名、学号、研究方向和预计使用资源；经导师或负责人确认后开通账号。开通后应尽快修改初始密码并配置 SSH key。

### Q2：项目代码仓在哪里？

项目代码统一放在实验室 Git 平台或共享代码目录中。进入具体课题后，应优先阅读项目根目录下的 `README`、`docs/` 和实验脚本入口。

### Q3：为什么我在某台机器上跑出的结果和别人不一样？

优先检查以下信息是否一致：

- 代码版本
- Python / 编译环境
- CPU / NUMA 绑定
- 数据集版本
- 驱动、固件和内核参数
- 是否使用相同的测试节点

## 二、组会与周报

### Q4：组会汇报应该讲什么？

至少讲清楚四件事：

1. 本周完成了什么
2. 遇到什么问题
3. 当前得到什么结论
4. 下周准备做什么

### Q5：没有明显进展时，组会怎么汇报？

也要汇报。重点说明：

- 卡在哪里
- 你已经排查过什么
- 需要什么帮助

## 三、实验与记录

### Q6：实验记录一定要写吗？

必须写。系统方向实验结论依赖环境强，若不记录参数、版本和平台信息，后续几乎无法复现。

### Q7：论文阅读笔记写到什么程度算合格？

不能只写摘要翻译。至少要能回答：

- 论文解决了什么问题
- 核心机制是什么
- 评测是否充分
- 与我们课题有什么关系

## 四、资源与流程

### Q8：如何预约 RDMA 或 GPU 节点？

按共享资源预约流程登记起止时间、用途和是否独占；长任务要提前同步，避免与他人实验冲突。

### Q9：报销模板和流程在哪里？

查看实验室公共资料中的报销与采购说明，模板一般按月份或事项归档。提交前应确认票据、审批流程和预算来源。

### Q10：我刚加入实验室，第一周优先看什么？

推荐顺序：

1. 研究方向与课题地图
2. 环境配置说明
3. 组会制度与考勤制度
4. 你所在项目的研究计划和论文材料
5. 实验记录与论文笔记规范
