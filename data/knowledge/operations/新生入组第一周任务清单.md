# 新生入组第一周任务清单

## 一、目标

新成员第一周的目标不是立刻产出研究结果，而是建立基本工作能力和实验室协作习惯。

## 二、第一周建议任务

### 第一天

1. 熟悉实验室成员与分工
2. 阅读研究方向与课题地图
3. 开通代码仓、服务器和共享存储账号
4. 确认本人的直接指导老师或项目负责人

### 第二天到第三天

1. 配置本地和服务器开发环境
2. 跑通项目 README 中的最小示例
3. 熟悉共享目录和日志归档方式

### 第四天到第五天

1. 阅读最近两次相关组会纪要
2. 阅读 2 到 3 篇与你方向相关的系统论文
3. 按实验室模板完成第一份论文笔记
4. 整理一份自己的问题清单

## 三、第一周必须掌握的内容

- 如何登录和使用服务器
- 如何查看项目 README 和实验脚本
- 如何记录实验结果
- 如何参加组会并汇报
- 如何提问和同步阻塞问题

## 四、第一周结束前建议产出

建议至少完成以下产出：

1. 一份环境配置记录
2. 一份论文阅读笔记
3. 一份项目理解笔记
4. 一份后续两周计划

## 五、常见误区

- 只看论文，不动手搭环境
- 只跑代码，不记录结果
- 有问题不及时问，导致卡住很久
- 不看组会纪要，导致不了解方向上下文
