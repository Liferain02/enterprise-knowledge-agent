# 信息安全管理制度

## 第一章 总则

### 第一条 目的

保护公司信息安全，防范信息泄露、篡改、破坏等安全风险。

### 第二条 适用范围

公司全体员工、合作伙伴及第三方服务商。

### 第三条 安全原则

1. 最小权限：只授予必要权限
2. 责任到人：明确安全责任
3. 预防为主：主动防范风险
4. 持续改进：不断完善机制

## 第二章 信息分类

### 第四条 密级划分

| 密级 | 定义 | 示例 | 传播范围 |
|------|------|------|----------|
| 绝密 | 核心机密 | 源代码、算法 | 限核心人员 |
| 机密 | 重要机密 | 客户数据、财务 | 限管理层 |
| 秘密 | 内部机密 | 员工信息、合同 | 限部门内部 |
| 内部 | 内部使用 | 管理制度、流程 | 全员 |
| 公开 | 对外公开 | 官网内容、新闻 | 无限制 |

### 第五条 敏感信息

1. 客户个人信息
2. 员工个人信息
3. 财务数据
4. 技术资料
5. 商业合同
6. 合作伙伴信息

## 第三章 访问控制

### 第六条 账号管理

1. 一人一账号，不得借用
2. 账号密码复杂度：8位以上含大小写数字
3. 密码有效期：90天
4. 密码历史：不能使用最近5个密码

### 第七条 权限管理

1. 权限申请需审批
2. 权限遵循最小原则
3. 权限定期复核
4. 离职立即回收权限

### 第八条 访问审计

1. 记录所有访问日志
2. 日志保留至少6个月
3. 定期审计异常访问
4. 违规行为追究责任

## 第四章 数据安全

### 第九条 数据加密

1. 传输加密：使用TLS/SSL
2. 存储加密：敏感数据加密存储
3. 备份加密：备份数据加密
4. 密钥管理：密钥分离存储

### 第十条 数据备份

1. 数据库：每日全量备份
2. 文件数据：每周全量备份
3. 备份测试：每月恢复测试
4. 备份保留：保留30天

### 第十一条 数据处理

1. 收集：需明确告知用途
2. 存储：期限符合法规要求
3. 使用：仅限授权用途
4. 销毁：安全彻底删除

## 第五章 网络安全

### 第十二条 网络隔离

1. 生产网与办公网隔离
2. 核心系统独立网络
3. 无线网络与有线网络隔离
4. 外部访问需通过VPN

### 第十三条 边界防护

1. 防火墙：部署网络防火墙
2. 入侵检测：部署IDS/IPS
3. 防病毒：部署终端防护
4. Web应用防护：WAF防护

### 第十四条 移动设备管理

1. 注册登记设备
2. 远程锁定擦除
3. 应用黑白名单
4. 禁止连接不信任网络

## 第六章 终端安全

### 第十五条 计算机管理

1. 必须安装防病毒软件
2. 系统补丁及时更新
3. 禁用不必要的端口
4. 禁止私搭服务器

### 第十六条 移动存储

1. 禁用USB存储设备
2. 加密U盘使用登记
3. 光盘使用管控
4. 介质报废需格式化

### 第十七条 安全软件

1. 必装软件：防病毒、桌面管控
2. 选装软件：需IT审批
3. 破解软件：严禁使用
4. 软件来源：官方渠道

## 第七章 物理安全

### 第十八条 机房管理

1. 门禁系统：授权进入
2. 温湿度控制：恒温恒湿
3. 消防设施：灭火系统
4. 电力保障：UPS+发电机

### 第十九条 办公区域

1. 门禁卡权限管控
2. 视频监控系统
3. 访客陪同制度
4. 纸张文档管控

## 第八章 应急响应

### 第二十条 安全事件

**事件分级**：
- 一级（重大）：核心系统入侵、数据泄露
- 二级（严重）：重要系统攻击、勒索病毒
- 三级（一般）：普通安全事件
- 四级（轻微）：未遂事件

**响应流程**：
1. 发现上报
2. 初步研判
3. 应急处置
4. 调查取证
5. 修复改进
6. 总结报告

### 第二十一条 应急预案

1. 数据泄露应急预案
2. 系统瘫痪应急预案
3. 勒索病毒应急预案
4. 网络攻击应急预案

## 第九章 培训与考核

### 第二十二条 安全培训

1. 入职培训：信息安全基础
2. 年度培训：全员安全意识
3. 专项培训：岗位技能培训
4. 应急演练：每年至少一次

### 第二十三条 考核问责

1. 安全责任书签状
2. 安全事件追责
3. 违规行为处罚
4. 安全绩效考核

## 第十章 附则

### 第二十四条

本制度由信息安全部负责解释，自2024年1月1日起施行。
