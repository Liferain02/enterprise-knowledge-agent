# 合同管理规定

## 第一章 总则

### 第一条 目的

规范公司合同管理，防范法律风险，确保合同合法有效。

### 第二条 适用范围

公司对外签订的所有经济合同均适用本规定。

### 第三条 合同原则

1. 合法合规：符合法律法规
2. 平等互利：双方权利义务对等
3. 诚实信用：如实陈述履行义务
4. 规范严谨：条款清晰无歧义

## 第二章 合同类型

### 第四条 合同分类

| 类型 | 说明 | 审批级别 |
|------|------|----------|
| 采购合同 | 采购设备、材料 | 部门+法务 |
| 销售合同 | 产品销售服务 | 部门+法务+财务 |
| 服务合同 | 服务外包、设计 | 部门+法务 |
| 租赁合同 | 办公场地、设备 | 部门+法务+行政 |
| 劳动合同 | 员工雇佣 | 人力资源+法务 |

### 第五条 合同模板

1. 法务部制定标准合同模板
2. 各部门使用标准模板
3. 特殊情况可申请非标模板
4. 非标模板需法务审批

## 第三章 合同签订

### 第六条 签订流程

```
需求部门 → 起草合同 → 部门负责人审核 → 法务审核 → 财务审核 → 领导审批 → 双方签字 → 归档
```

### 第七条 审批权限

| 金额 | 审批人 |
|------|--------|
| 10万元以下 | 部门负责人 |
| 10-50万元 | 部门负责人+法务经理 |
| 50-200万元 | 部门负责人+法务经理+财务总监 |
| 200万元以上 | 部门负责人+法务经理+财务总监+CEO |

### 第八条 合同审查要点

1. 主体资格：对方是否具有签约资格
2. 合同标的：是否明确具体可执行
3. 权利义务：是否对等合理
4. 违约责任：是否明确具体可执行
5. 争议解决：是否有利于公司
6. 风险条款：是否有效规避风险

## 第四章 合同履行

### 第九条 履行监控

1. 合同签订后复印给执行部门
2. 建立合同履行台账
3. 履行节点提前提醒
4. 异常情况及时报告

### 第十条 变更解除

1. 变更需签订补充协议
2. 解除需签订解除协议
3. 变更解除需原审批流程
4. 留存完整变更解除文件

### 第十一条 验收结算

1. 严格按照合同验收
2. 验收单据妥善保存
3. 结算按合同约定执行
4. 发票与验收单匹配

## 第五章 合同档案

### 第十二条 归档要求

1. 合同原件妥善保管
2. 复印件供执行部门使用
3. 建立电子档案索引
4. 合同档案保存10年

### 第十三条 借阅管理

1. 借阅需登记备案
2. 借阅期限不超过7天
3. 重要合同需领导审批
4. 借阅不得复制带走

## 第六章 附则

### 第十四条

本规定由法务部负责解释，自2024年1月1日起施行。
