## Deep 全阶段污染测试

测试刻意让 restricted 文档绕过第一层检索过滤、混入 pipeline 返回，再使用无权用户执行完整 Deep 链路。以下表面均断言不得出现受限文档标题、路径或正文标记：

1. EvidencePackage；
2. AnalysisReport / Claim；
3. ReviewReport；
4. Generation 使用的 retrieval_context；
5. research_trace；
6. source cards / retrieved_docs；
7. Final Answer。

Revision 补检索另有独立用例：即使 targeted query 返回 restricted 文档，也会在合并 EvidencePackage 之前再次执行 `check_doc_access`。两条传播测试均通过，未发现 ACL 拒绝后继续传播的路径。

## 结论边界

该报告证明当前确定性权限协议及 Deep state 传播没有已知越权；它不声称覆盖未来新增 metadata 维度，也不改变现有角色、visibility 或 project 权限规则。
