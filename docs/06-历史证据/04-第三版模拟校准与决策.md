## 3. 可执行性门槛决策

已有冻结因果消融显示，可执行性门槛相对完整修订：

- 声明 F1：`+0.006`；
- Faithfulness：`-0.044`；

- 输入 Token：降低 `16.0%`；
- 输出 Token：降低 `18.5%`。

预先固定的质量容差为 `0.02`，Faithfulness 下降 `0.044`，因此：

- 成本预门禁通过；
- 质量预门禁失败；
- 模拟建议为 `revert_actionability_gate`。

用户明确授权将模拟结果作为当前开发决策依据，因此本轮撤销可执行性门槛。这里的“开发决策”不改变评测报告中的事实标签：最终独立人工校准状态仍然是 pending。

## 4. 实现变化

撤销前：

```text
Reviewer = REVISE
+ 无结构化 unsupported ReviewItem
→ 自动改写为 PASS
→ 跳过 Revision
```

撤销后：

```text
Reviewer = REVISE
→ 保留原决定
→ 执行一次受限 Revision
→ Generation
```

边界保持不变：

- 修订最多一次；
- `NEED_MORE_EVIDENCE` 仍走现有定向补证据路径；
- ACL 未通过仍默认拒绝；
- 没有新增智能体；
- 没有增加循环；
- 普通检索问答不受影响。

旧的执行轨迹字段继续保留用于审计和冻结评测兼容，并明确记录：

```text
actionability_gate_enabled = false
```

## 5. 效果解释

本次不是根据评测结果重新生成答案，而是采用冻结因果消融已经生成的 `deep_full` 分支。该分支与 `deep_gated` 共享完全相同的资料研究员、分析员和审核员上游状态，仅在“是否跳过修订”这个门槛处分叉，因此可以直接用于解释回退效果。

回退后的预期取舍是：

- 平均 Faithfulness 从 `0.737` 恢复到约 `0.781`；
- 声明召回率从 `0.662` 提高到约 `0.734`；
- 声明 Precision 可能从 `0.433` 降到约 `0.360`；
- P50 延迟从约 `35.7s` 增加到约 `42.1s`。

这是一个偏质量、牺牲部分延迟的保守选择。深度研究模式本来就是用户显式开启的复杂科研模式，因此当前取舍合理；普通模式仍负责低延迟常规问答。
