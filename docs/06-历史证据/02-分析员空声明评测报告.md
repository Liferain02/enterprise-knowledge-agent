# 实验室科研助手：分析员空声明评测报告

> 历史证据：已完成的门禁修复记录，不是当前待办。文中的提交号仅用于定位当时对照版本。

## 1. 评测目的

验证 `ca52b7c` 增加的确定性门禁是否解决“证据包非空但分析员没有形成声明，审核员仍可能错误 PASS”的已知问题，同时确认正常结构化分析、证据支持和 ACL 没有回退。

## 2. 对照与数据

- Before：`ca52b7c^` 的确定性复核规则；
- After：`ca52b7c` 及之后保留的当前规则；
- 固定 7 条离线样本：1 条已知空声明失败，6 条正常复杂任务结构化回归；
- 不调用模型、不读取真实数据库、不修改 V3 Gold、评分器或阈值。

## 3. 结果

P50/P95 为毫秒级确定性规则耗时；After 的修订 logical 调用次数上界为 1，符合现有“最多一次修订”约束。该离线脚本不测真实 LLM 延迟和 Token，真实成本仍应以已有深度研究模式评测记录为准。

## 4. 结论

本次门禁达到任务书保留标准：已知空声明错误放行被消除，正常样本无回归，Faithfulness 代理指标未下降，ACL violation 保持为 0，成本增量可解释为最多一次既有修订。深度研究模式主链可以冻结，不再针对该失败继续增加智能体或循环。
