# 历史证据说明

本目录保存过去的评测、真实验收和边界记录，目的是让面试时能够说明“问题如何发现、如何修复、如何验证”。它们不是当前开发计划，也不代表项目仍在等待这些步骤。

## 1. 如何阅读

- 先阅读 [`docs/00-总览/00-文档总览.md`](../00-总览/00-文档总览.md) 和当前评测收口说明。
- 再按需要查看权限边界、空声明门禁、多轮记忆和真实产品验收。
- 报告里的日期、提交号、模型和指标只对当时快照负责；不能和当前代码混为一谈。

## 2. 文件状态

| 文件 | 保留价值 | 当前状态 |
|---|---|---|
| 文档权限元数据边界说明 | 解释 ACL 回查和旧数据兼容边界 | 历史限制，当前仍需知晓 |
| 分析员空声明评测报告 | 说明确定性门禁如何消除已知故障 | 已完成，作为修复证据 |
| 第三版声明级评测阶段报告 | 说明声明级评测设计和成本观察 | 阶段记录，不再追加调参 |
| 第三版模拟校准与决策 | 区分模拟评分和真人评分 | 模拟记录，不能冒充真人结果 |
| 多轮与记忆真实验收报告 | 说明 Mem0、确认和撤销链路 | 历史验收，当前功能以代码为准 |
| 真实产品验收报告 | 记录早期端到端问题和修复 | 历史快照，不是当前故障清单 |

## 3. 当前结论

历史报告中出现的“下一步”“P1/P2”只表示当时的建议。当前项目已经完成核心收口，除非新的回归、权限问题或用户反馈提供失败证据，否则不继续沿这些旧路线扩展 Agent、基础设施或评测平台。
