## 一、RAG 多阶段检索测试

### 1.1 测试方法

检索链路：**BM25 关键词检索 + 向量相似度检索 → gte-rerank-v2 精排 → Top 5 输出**

对 10 条代表性查询（覆盖员工手册、招聘、绩效、培训、财务、行政、信息安全共 7 类文档），逐一验证精排后 Top 5 是否命中目标文档。

### 1.2 测试结果

```
R@5（召回率@5）= 90.0%   (9/10)
精排过滤率    = 67%     (候选 100 → 精排 33)
```

| 查询 | 命中 | 来源文档 |
|------|------|---------|
| 公司的年假政策是什么？ | ✓ | 员工手册 |
| 试用期多长时间？ | **✗** | 员工手册 |
| 工资什么时候发放？ | ✓ | 员工手册 |
| 社会招聘的流程是什么？ | ✓ | 招聘管理制度 |
| 内部推荐有奖励吗？ | ✓ | 招聘管理制度 |
| 绩效考核等级有哪些？ | ✓ | 绩效考核制度 |
| 新员工培训多长时间？ | ✓ | 培训发展体系 |
| 差旅费报销标准是多少？ | ✓ | 财务报销制度 |
| 上班时间是几点？ | ✓ | 行政办公管理制度 |
| 信息密级如何划分？ | ✓ | 信息安全管理制度 |

### 1.3 结论

- **R@5 = 90%**：检索链路整体质量良好，9/10 条查询能在精排后 Top 5 命中正确文档
- **"试用期多长时间？"未命中**：可能原因——文档中对应内容表述为"试用期为 XX 个月"，与查询的问法存在表述差异，需优化 chunk 切分或 query 改写
- **精排过滤率 67%**：`gte-rerank-v2` 有效过滤掉弱相关文档，保留强相关候选，显著提升排序质量

## 二、Supervisor 路由决策测试

### 2.1 测试方法

直接调用 `supervisor_node()` 函数，输入 115 条测试查询，验证路由目标与预期 Agent 是否一致。

| Agent | 职责 |
|-------|------|
| knowledge_agent | 回答企业知识库相关问题 |
| operation_agent | 执行操作类任务（时间/计算/工具调用） |
| general_agent | 通用对话、闲聊 |

### 2.2 整体结果

```
整体准确率: 110/115 = 95.7%
```

### 2.3 分类指标

| 类别 | 期望数 | 正确数 | Precision | Recall | F1 |
|------|--------|--------|-----------|--------|-----|
| 知识检索（knowledge_agent） | 42 | 40 | 93.0% | 95.2% | 94.1% |
| 操作执行（operation_agent） | 37 | 34 | 100.0% | 91.9% | 95.8% |
| 通用问答（general_agent） | 36 | 36 | 94.7% | 100.0% | 97.3% |

## 三、Planner 复杂度判断测试

### 3.1 测试方法

调用 `planner_node()` 判断 45 条查询的复杂度（simple / complex），验证判断结果与预期是否一致。

### 3.2 结果

```
整体准确率: 36/45 = 80.0%
```

### 3.3 主要问题

| 问题 | 描述 | 影响 |
|------|------|------|
| 规则快速路径过于保守 | ≤40 字含"？"直接判 simple，但复合意图应进 LLM | 漏判 7 条 |
| 对比关键词识别缺失 | "张三和李四谁的KPI更高？" 无显式"对比"字样 | 漏判 1 条 |
| 极短对比/总结词 | "对比"、"总结" 单字被规则误判 | 漏判 2 条 |

## 六、改进建议

| 优先级 | 问题 | 改进方案 |
|--------|------|---------|
| **P0** | "试用期"类表述差异导致检索漏检 | 优化 chunk 切分，增加同义词扩展 |
| **P0** | QA agent 初始化耗时过长 | 复用 agent 实例，避免每次重建 |
| **P1** | Planner 规则快速路径过于保守 | 增加操作类关键词检测（"算"、"多少"、"剩"等） |
| **P1** | 对比句式识别缺失 | 补充"谁更高/低"、"A和B哪个"等模式 |
| **P2** | Supervisor 5 条 operation 误判为 knowledge | 补充操作类意图关键词 |
